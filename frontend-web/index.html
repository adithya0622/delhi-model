    the return leg

    Chemistry pushing back on the weather

    One-way models stop at "shallow layer makes dirty air". The return leg is that dirty air dimming the surface, cooling it, and making the layer shallower still. Each hour is solved as a fixed point, so the numbers on this loop are mutually consistent rather than sequential guesses.

    — Picard iterations
    to converge
    1. PM2.5 —µg/m³ surface load
    2. AOD — extinction × depth
    3. shortwave —W/m² withheld from ground
    4. surface —°C cooling
    5. mixing depth —% suppressed → back to PM2.5

    At night the shortwave term is necessarily zero. The loop stays closed anyway through a surface thermal-memory term: an afternoon spent under thick aerosol hands the following night a colder surface to build its inversion on.

    ground truth

    Live monitoring network

    CPCB stations via OpenAQ, ordered worst first. The nearest reading also anchors hour 0 of the forecast, so the curve opens on observed air rather than on climatology.

    What this model is

    A parameterised single-column surrogate: a two-reservoir box model with prognostic mass budget, an aerosol–radiation–boundary-layer feedback solved to a fixed point each hour, and Gaussian plume transport for stubble smoke. Emission fluxes are hand-set to reproduce the order of magnitude and diurnal shape of CPCB Delhi climatology.

    What it is not

    It is not a chemistry transport model, and no accuracy figure is quoted anywhere in this interface because no withheld-data backtest exists in the repository. Every number here is model output or a live upstream reading, labelled as one or the other.
